For anyone who runs a meeting

The Meeting Timer

Your agenda on screen with a big countdown, a gentle chime when it's time to move on, and a parking lot.

Monday: run your next PLC with it on the screen.

Remix menu
Make it yours
  • Change the agenda to my meeting: ___ (10 minutes), ___ (15 minutes), ___ (5 minutes).
  • Show our team norms along the bottom: ___.
  • Use our school colors: ___ and ___.
Make it useful
  • Add a protocol mode: 5 minutes of silent writing, then 10 minutes of discussion, with a different chime for each.
  • Add a spinner that picks who takes notes and who keeps time.
  • Add a button that copies the parking lot as a list I can paste into our notes.
Make it fun
  • When time runs out, play a game-show buzzer instead of the chime.
  • If we finish the agenda early, celebrate with confetti.
Look inside (no AI needed)
  • Press Play, then Show the code. Find AGENDA, change the minutes for one item, and press Run my changes.

What Google Sites does to pasted code

It runs in a sealed box on your page. That keeps your site safe, and it sets the limits: the page can't remember anything between visits, so saved settings and scores vanish; it can't reach the rest of your site or your visitors' accounts; sound and full screen wait for a tap; and a very long page may be refused or load slowly. One box holds one page, and it shows at the size you drag it to, so build for a box, not a window.

If what you pasted doesn't fit or doesn't behave, hand your AI this:

Make this one self-contained HTML file for a Google Sites embed box about 800 pixels wide: no outside libraries, fonts, or images; nothing saved between visits; no sound until a tap; large type that works on a phone; and as short as it can be while keeping everything it does.

For curriculum leads and anyone with a deep folder

The Drive Inventory

Point it at a folder. It reads every folder inside and writes a Sheet: each document, its type, its link, and when it last changed.

Monday: a whole curriculum folder, one search away.

  1. Paste the script into a new project. Put your folder's ID between the quotes at the top.
  2. Choose inventory, press Run, and read the permission screen: Drive and Sheets.
  3. Open the Execution log for the link.
Remix menu
Make it useful
  • Add a column for who owns each file.
  • Skip anything that hasn't changed in two years, and list those in a second tab instead.
  • Make the Link column a clickable "Open" instead of the whole address.
Make it careful
  • Explain exactly which permission each line needs, and whether any line could change or delete a file. (It shouldn't.)

For anyone who makes the same Doc many times

The Doc Multiplier

One template Doc and a Sheet of names. It makes a copy for each row, named for the row, gathers them in a folder, and writes each link back into the Sheet.

Monday: a planning doc for every team, made in one press. Practice with made-up names.

  1. Paste the script into a new project. Put the template Doc's ID and the Sheet's ID at the top.
  2. Choose multiply, press Run, and read the permission screen: Drive and Sheets.
  3. Open the Execution log for the folder's link.
Remix menu
Make it useful
  • Replace the words TEAM and DATE inside each copy with the row's name and today's date.
  • Skip a row if column B already has a link, so I can run it again safely.
  • Share each copy with the email address in column C, as an editor.
Make it careful
  • Before anything is copied, show me how many copies it's about to make and stop if it's more than 30.

Where do I paste it?

Gemini

Open gemini.google.com. In the prompt bar, choose Canvas (look in the + menu or under Tools), then paste.

Claude

Open claude.ai and paste. The starter appears beside the chat as an artifact. Nothing there? Turn on artifacts in Settings › Capabilities.

ChatGPT

Open chatgpt.com and paste. When the code appears, switch on Preview on the code block.

Microsoft Copilot

In a Microsoft district? Signed in with a school account, Copilot Pages can build and preview small apps too.
